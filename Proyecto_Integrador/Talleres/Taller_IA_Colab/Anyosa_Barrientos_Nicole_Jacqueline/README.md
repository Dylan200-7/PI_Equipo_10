# Taller de IA

## ¿Qué aprendimos?

En este taller aprendimos a utilizar Python para realizar análisis de datos y desarrollar modelos de **inteligencia artificial orientados a la predicción**.

Durante el taller realizamos:

* Carga y exploración de datos utilizando **Pandas**.
* Análisis de las características de una base de datos.
* Visualización de datos mediante gráficos y `pairplot`.
* Análisis de **correlación** entre las variables mediante matrices y `heatmap`.
* Preparación de los datos para un modelo predictivo.
* División de los datos en conjuntos de **entrenamiento y prueba**.
* Aplicación de **regresión lineal** para predecir el consumo de energía.
* Análisis de los coeficientes y resultados del modelo.
* Comparación entre valores reales y valores predichos.
* Análisis de los **residuos** para evaluar las predicciones.
* Generación de datos artificiales para experimentar con modelos.
* Aplicación de un **árbol de decisión** para realizar predicciones.
* Análisis del **error cuadrático medio (MSE)** y de la importancia de las características.


## ¿Qué fue lo más relevante?

Lo más relevante del taller fue aprender a usar los datos para hacer **predicciones** mediante modelos de IA. También entendimos que antes de crear un modelo tenemos que conocer y analizar los datos, ver cómo se relacionan las variables y luego comprobar si las predicciones que obtenemos son correctas.

Además, aprendimos a revisar los resultados de los modelos mediante los **coeficientes, las correlaciones, los errores y los residuos**, para entender mejor cómo funciona el modelo y qué variables son más importantes.
