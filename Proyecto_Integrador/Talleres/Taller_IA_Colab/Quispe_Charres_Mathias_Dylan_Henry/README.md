# Análisis de Regresión y Modelos Predictivos

## Descripción

En este trabajo se realizó un análisis de datos utilizando **Python**, aplicando diferentes técnicas de análisis estadístico y aprendizaje automático.

El objetivo fue explorar los datos, analizar la relación entre las variables y aplicar modelos de regresión para realizar predicciones.

## Desarrollo

Durante el trabajo se realizaron las siguientes actividades:

* Importación de librerías como **NumPy, Pandas, Matplotlib, Seaborn y Scikit-learn**.
* Carga y exploración del conjunto de datos.
* Obtención de estadísticas descriptivas.
* Visualización de la distribución de los datos.
* Creación de una **matriz de correlación**.
* Elaboración de un **mapa de calor (Heatmap)**.
* Uso de gráficos de dispersión para observar la relación entre variables.
* División de los datos en **70% para entrenamiento y 30% para prueba**.
* Implementación de un modelo de **Regresión Lineal**.
* Realización de predicciones con los datos de prueba.
* Visualización de valores reales, valores predichos y residuos.
* Implementación de un **Árbol de Decisión para regresión**.
* Evaluación del modelo mediante el **Error Cuadrático Medio (MSE)**.
* Análisis de la importancia de las características.
* Aplicación del método de **Mínimos Cuadrados Ordinarios (OLS)**.

## Herramientas utilizadas

* Python
* Jupyter Notebook
* NumPy
* Pandas
* Matplotlib
* Seaborn
* Scikit-learn
* Statsmodels

## Resultado

El desarrollo permitió comprender el proceso básico para trabajar con modelos de regresión, desde la exploración y visualización de los datos hasta el entrenamiento y evaluación de modelos predictivos.

Se aplicaron diferentes métodos para analizar el comportamiento de las variables y observar qué tan bien los modelos pueden aproximarse a los valores reales.
