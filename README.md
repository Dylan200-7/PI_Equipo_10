## 🥔 Kartoffelmachine

### Clasificador inteligente de papas

**Kartoffelmachine** es un sistema que busca automatizar la clasificación de papas mediante el uso de **visión artificial y machine learning**.

El sistema analiza las características de cada papa para determinar aspectos como:

* ⚖️ **Tamaño:** pequeña, mediana o grande.
* 👀 **Calidad:** identificación de papas verdes o con defectos visibles.
* 📷 Procesamiento de imágenes mediante cámara.
* 🤖 Clasificación utilizando un modelo de inteligencia artificial.

El objetivo principal es desarrollar una alternativa tecnológica que permita mejorar el proceso de selección de papas y contribuir a la reducción de pérdidas poscosecha.

---

## 🎯 Objetivo del Proyecto

Diseñar e implementar un sistema inteligente, modular y de bajo costo capaz de **identificar y clasificar papas automáticamente**, integrando hardware, software y técnicas de inteligencia artificial.

Kartoffelmachine busca contribuir a:

* Reducir errores producidos durante la clasificación manual.
* Detectar papas que presentan características no aptas para su comercialización.
* Mejorar el aprovechamiento de los productos agrícolas.
* Reducir pérdidas y desperdicios.
* Explorar el uso de tecnologías accesibles en procesos agrícolas.

---

## ♻️ ODS 12 — Producción y Consumo Responsables

Kartoffelmachine se relaciona principalmente con el **Objetivo de Desarrollo Sostenible 12**, que busca garantizar modalidades de consumo y producción sostenibles.

Una clasificación adecuada de los productos agrícolas permite mejorar su aprovechamiento y disminuir las pérdidas generadas durante los procesos de selección y distribución.

### Metas relacionadas

**Meta 12.3**

> De aquí a 2030, reducir las pérdidas de alimentos en las cadenas de producción y suministro, incluidas las pérdidas posteriores a la cosecha.

**Meta 12.5**

> Reducir considerablemente la generación de desechos mediante actividades de prevención, reducción, reciclado y reutilización.

## 💡 Evolución del Proyecto

Kartoffelmachine comenzó como un proyecto desarrollado por el **Equipo 7 del curso Fundamentos de Diseño 2025-2**.

Durante esa primera etapa se desarrolló el concepto inicial del sistema y un primer prototipo orientado a demostrar la viabilidad de la propuesta.

Actualmente, como **Equipo 10 de Proyecto Integrador 2026-2**, buscamos continuar y mejorar el proyecto mediante el desarrollo de una nueva versión.

### Principales áreas de mejora

* 🧠 Modelo de inteligencia artificial.
* 📷 Sistema de captura de imágenes.
* 💡 Control de iluminación.
* ⚙️ Sistema mecánico de clasificación.
* 🖨️ Rediseño y modelado 3D.
* 💻 Desarrollo de software.
* 🌐 Integración IoT.
* 📊 Registro y visualización de resultados.
* 🔌 Integración completa de los componentes electrónicos.

                  │

        ┌─────────────────┐
        │ Captura de      │

                 │
                 ▼
        ┌─────────────────┐
        │ Procesamiento   │
        │ de imagen       │
        └────────┬────────┘
                 │
                 ▼
        ┌─────────────────┐
        │ Modelo de       │
        │ Machine Learning│
        └────────┬────────┘
                 │
                 ▼
        ┌─────────────────┐
        │ Clasificación   │
        └────────┬────────┘

          ▼      ▼      ▼
